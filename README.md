# Intune Custom Compliance Evaluation Interval Tuner (Graph Audit & Patch)

> Audits Intune custom compliance policies via Microsoft Graph and (optionally) patches the custom compliance evaluation interval with schema-safe, retry-capable Graph calls.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/intune-custom-compliance-interval-tuner.git
cd intune-custom-compliance-interval-tuner

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Microsoft Graph, Intune Device Compliance Policies

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
